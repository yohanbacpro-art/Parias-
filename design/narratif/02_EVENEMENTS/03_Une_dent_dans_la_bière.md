# Une dent dans la bière

**Lieu :** Taverne de Port-Noir

## Scène d'ouverture

Un Khesh massif joue aux dés avec trois marins. L'un d'eux accuse le Khesh de tricher. Le Khesh ne répond pas. Il ramasse simplement les pièces. Le marin lui crache dessus.

Le silence tombe une seconde avant que la table ne vole en éclats. Une dent atterrit dans la chope de Yohan.

Les amis du marin dégainent. D'autres clients se lèvent, moins pour intervenir que pour choisir le camp qui leur permettra de voler les morts.

## Choix visibles

1. **Quitter la salle avant que tout dégénère.**
2. **Aider le Khesh.**
3. **Profiter du chaos pour calmer tout le monde par la menace.**

## Branches développeur — SPOILERS

### Partir
Aucune implication immédiate, mais le Khesh peut être retrouvé plus tard.

### Khesh
Combat de taverne. S'il survit, le Khesh peut devenir contact, compagnon temporaire ou relais vers une tribu.

### Intimidation
Test basé sur réputation. Échec : mêlée générale. Réussite : Yohan obtient le respect de certains mercenaires et l'hostilité d'autres.

## Mémoire persistante

- contact Khesh
- réputation Port-Noir
- blessures possibles
